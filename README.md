# When Are We Free? 📅

A simple shared availability calendar for friends.

Each person in a group is assigned a unique colour and can select the dates
they are available to hang out.

If multiple people are available on the same date, their colours are combined
on that date so the group can quickly see when everyone is free.

## Project Status

🚧 Currently in development.

The project is being built frontend-first.

Current focus:

- Calendar interface
- Person selection
- Colour-based availability
- Responsive design
- Automatic month generation

The backend and database will be added later.

## Planned Features

- Create a shared group
- Join a group using a username and access code
- Add people to a group
- Assign each person a unique colour
- Select and deselect available dates
- Display multiple colours when several people are available
- Automatically generate upcoming months
- Store availability in a database
- Access the same calendar from multiple devices
- Mobile-friendly design
